🚀 HERA – PCOD Tracker & Stabilizer
📌 Problem

PCOD affects millions of women causing hormonal imbalance, irregular periods, and infertility. There is no proper personalized solution for early detection and lifestyle stabilization.

💡 Solution

HERA is an AI-powered PCOD tracker that provides early detection, personalized diet plans, and continuous health monitoring using wearable devices.

⚙️ Features
AI-based PCOD prediction
Personalized diet & exercise plans
Health monitoring with alerts
Wearable device integration
Community support
🛠️ Tech Stack
Flutter (Frontend)
Firebase / Node.js (Backend)
Random Forest (Machine Learning)
ESP32 + Sensors (Hardware)
📊 Dataset
541 samples collected from hospitals
Achieved 93% accuracy using Random Forest
